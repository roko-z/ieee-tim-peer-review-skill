# 分领域审稿检查清单

按论文实际主题选用相关项目，不要将某个论文的特殊问题强加到所有稿件。

## 1. 所有仪器测量论文

- [ ] 明确 measurand（被测量）、直接传感器输出、计量单位与目标输出之间的转换。
- [ ] 量纲分析和单位换算正确，零值、负值、饱和、量程外输出规则明确。
- [ ] 参考仪器型号、准确度、校准状态、溯源链、测量同步和参考值处理已披露。
- [ ] 区分准确度、精密度、响应时间、分辨率、LOD、重测/复现、LoA。
- [ ] 灵敏度、交叉灵敏度、漂移、基线和系统级不确定度已分析。
- [ ] 比较包含各自最有代表性的强基线，声明对照条件一致/差异来源。
- [ ] 数据样本数、独立实验次数、分组规则、置信区间、多重比较可复现。
- [ ] 研究适用范围与实验真实覆盖范围一致，不将搜索参数当已验证量程。

## 2. 流量 / 阵列 / k–ω 反演 / 信号处理

- [ ] Taylor 冻结湍流条件、对流速度与截面平均速度的校准关系有物理说明。
- [ ] 管径内径、介质温度、雷诺数、管材、入口扰动、阵列位置报告完整。
- [ ] 阵元间距、阵元个数、实际孔径、增益/相位一致性和同步精度清楚。
- [ ] 理想导向向量是否与实际通道传递函数一致；是否有校准/均衡。
- [ ] k–ω 空间混叠和频带选择受到物理约束，避免将有条件的频率示例当固定上限。
- [ ] 协方差快照数、重叠、特征子空间维度与选择规则已报告；相关结构干扰风险得到说明。
- [ ] Hann/Kaiser 参数和复杂窗口真实收益通过同条件消融体现。
- [ ] FFT 剪枝/多项式加速与估计器精度提升分开主张，数值等价性有报告。
- [ ] 基准算法的决策规则、归一化、差分操作、调参预算一致或差异有解释。
- [ ] 标定独立性（包括调参是否泄漏）、重新安装、跨天或外部干扰能力得到合理约束。
- [ ] 算法复杂度、CPU/MATLAB 耗时、硬件执行时间、端到端延迟不混同。

## 3. 电化学 / 导纳指纹 / PAHs / 分类

- [ ] 电极结构、材料、连接方式、参比/对电极、电位范围、电解液、溶剂比例明确。
- [ ] 分析物是否稳定溶解？名义配制浓度与实际浓度是否分开，难溶物需独立核验或收缩主张。
- [ ] 对于电双层/吸附解释，是否考虑背景电化学反应、表面氧化/还原、溶液电导与污染膜变化。
- [ ] 方波激励幅值/频率、复数基频提取、相位校准和测量噪声充分说明。
- [ ] 特征明确：Re(Y)、Im(Y)、|Y|、相位、差分还是绝对差分；保留/丢弃何种信息。
- [ ] PCA 解释方差不冒充分类准确度；50 样本 / 831 特征等高维小样本需防过拟合。
- [ ] CV/交叉验证避免同电极/同制备批次/同浓度泄漏；最好有跨天、跨电极或独立批次测试。
- [ ] 准确率应辅以类别数、每类混淆矩阵、折间波动；小样本可校核预测计数。
- [ ] LOD 的 S/N、空白噪声、检测/定量范围、低浓度重复数和校准曲线一致。
- [ ] 传感器再生、清洗后性能、电极间一致性、重复使用寿命及总检测周期明确。
- [ ] Proof-of-Concept 单物质溶液与真实消防废水之间的应用边界明确；混合物/基质干扰未验证不得声称已部署。

## 4. 生物医学可穿戴 / 泪液蒸发 / 湿度扩散

- [ ] 相对湿度（0–1 比例还是 0–100%）与水蒸气分压计算一致。
- [ ] 蒸发通量 g/(m²·h) 与质量流率 g/h 不混同；传输系数量纲正确。
- [ ] Fick 扩散假设在半开放腔、呼吸/空调气流影响下适用性得到讨论。
- [ ] 皮肤背景扣除是怎样建立的？面积比例假设和背景漂移得到验证或限制。
- [ ] 面积经验公式存在非物理输出时有裁剪/剔除规则；面积测量是否同步。
- [ ] 两传感器差分精度 ≠ 单个湿度传感器出厂准确度；系统级不确定度需量化。
- [ ] 有参考仪器时报告 Bland–Altman 偏差、LoA、置信区间、非正数据对数处理。
- [ ] 左右眼/机械安装/参考仪器位置的混杂因素受到控制或限制结论。
- [ ] Friedman 及两两比较原始和修正后 p 值一致；重复测量不可当独立样本。
- [ ] 环境监测与实际补偿区分；2 Hz 采样频率与传感器/滤波后真实响应时间区分。
- [ ] 正常人概念验证不直接声称已用于干眼诊断或真实日常佩戴监测。
