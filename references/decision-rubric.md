# 审稿处理建议与证据强度判断

## A. 处理建议规则

| 建议 | 适用情形 | 审稿语言 |
|---|---|---|
| Accept | 严格审查后已无实质性问题，极少见 | 结果由现有证据充分支持 |
| Minor Revision | 核心物理链条、验证、结论完整，仅剩非关键完善 | clarifications / presentation / minor additional details |
| Major Revision | 核心主张尚缺重要证据，但可通过补充验证、重分析或收缩结论合理修复 | substantive concerns regarding measurement validity / uncertainty / generalization |
| Reject | 核心机理/数据/创新存在无法以合理返修修复的缺陷 | fundamental validity concerns; specify evidence precisely |

**不能机械地按条数判定**：一条致命单位错误或明显数据泄漏，可能比十条拼写问题更重要。

## B. 证据等级

- E1（直接证据）：原文确切数值、公式、图表或直接矛盾；例如同一数据的不同 p 值。
- E2（可重复推导）：由原文量及明示假设可得；例如采样间距对应理论波数边界，先写约束条件。
- E3（风险/假设）：可能存在的效应但尚无直接证据；例如结构振动混入主子空间、难溶物析出。要求验证或收缩主张，不判定已经发生。

在每条评论草稿旁标 E1/E2/E3；正式英文稿通常不公开标签。

## C. 重要性排序

- P0 关键：可能推翻核心测量定义、主要数据或结论；如量纲、参考真值、训练集泄漏。
- P1 高：显著影响推广或比较结论；如跨天重复性、关键机制未排除替代解释、基线不公平。
- P2 中：影响可复现或完整性；如未披露 FFT 长度、滤波参数、安装细节。
- P3 低：格式、术语、图注或轻微写作问题。

建议优先选择 P0/P1，适当纳入必需的 P2。一个评论最好给出一个明确行动，而不是罗列十项不分轻重的任务。

## D. R1/R2 返修审查特殊规则

先建立 `旧意见 / 作者具体回复 / 新增证据 / 是否解决 / 本轮是否仍需提出` 矩阵。

- 已解决：不重复要求。
- 部分解决：先肯定改进，再明确未解决的证据缺口。
- 仅解释而无验证：判断解释是否足以支持该稿的定位；未必一律要求做全新实验。
- 新增数据/公式引入矛盾：可以提出新问题，但说明由修订导致。

## E. 审稿强度自检

输出前自问：我是否把“合理疑问”写成了“证实错误”？我有没有要求作者重做已经完成的实验？要求是否超出 Proof-of-Concept 研究定位？我提出的意见是否会改变对主结论的判断？
